# Información para completar la página de ciudad

1. Consolidado de indicadores de Recurso hídrico, Aire y Ruido, con unidad, ámbito, periodo y responsable de la fuente.
2. Visitas IVC: estados definidos, totales por periodo/tema/territorio y reglas para evitar duplicación. Aclarar si las evidencias son públicas y su relación con cada visita.
3. Hallazgos, puntos de vertimiento y concesiones: fuente y fecha de corte; clasificación de estados y alcance de competencia.
4. Series de calidad del aire y ruido: contaminante o variable, unidad, ubicación y criterios técnicos de interpretación.
5. Geodatos y documentos públicos: coordenadas verificadas, capas, metadatos y enlaces estables.
6. Acuerdo de actualización con el equipo: archivos periódicos o API, periodicidad y responsables. No se requiere definir una API para revisar este mockup.

No hacen falta estos insumos para evaluar la composición visual. Sí hacen falta para sustituir los valores demostrativos y publicar cifras oficiales.
